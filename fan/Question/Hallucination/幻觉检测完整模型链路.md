  六、YAML 配置完整示例

  hallucination_mitigation:
    enabled: true

    # 模型 A: 事实核查分类器 (请求阶段, 判断是否需要 fact check)
    fact_check_model:
      model_id: models/mom-fact-check-classifier       # ModernBERT 序列分类
      threshold: 0.7                                    # P(FACT_CHECK_NEEDED) >= 0.7 才触发
      use_cpu: true

    # 模型 B: 幻觉检测器 (响应阶段, Token 级检测)
    hallucination_model:
      model_id: models/mom-hallucination-detector       # ModernBERT Token 分类
      threshold: 0.5                                    # Token 幻觉置信度阈值
      use_cpu: true
      min_span_length: 2                                # 至少 2 个 token 才算 span
      min_span_confidence: 0.3                          # span 平均置信度阈值
      enable_nli_filtering: true                        # 启用 NLI 误报过滤
      nli_entailment_threshold: 0.75                    # ENTAILMENT 置信度 >= 75% 视为误报

    # 模型 C: NLI 模型 (可选, 响应阶段, 对每个 span 做推理验证)
    nli_model:
      model_id: models/tasksource-ModernBERT-base-nli   # 推荐: tasksource/ModernBERT-base-nli
      threshold: 0.7                                    # NLI 置信度阈值
      use_cpu: true

  三个模型在请求生命周期中的位置：

  请求到达
    │
    ├─ [模型A] FactCheck 分类器: "这个问题需要事实核查吗？"
    │    → ctx.FactCheckNeeded = true
    │
    ├─ 检查 tool context / RAG context 是否存在
    │    → ctx.ToolResultsContext = "..."
    │
    ├─ 请求转发给 LLM → LLM 返回响应
    │
    ├─ [模型B] Hallucination 检测器: "响应中哪些 token 没有上下文支撑？"
    │    → spans: ["每日最大剂量6g", "每2小时服用一次"]
    │
    └─ [模型C] NLI 模型 (仅 use_nli=true): "每个 span 与上下文是什么关系？"
         → span1: CONTRADICTION (severity=4, 与上下文直接矛盾)
         → span2: CONTRADICTION (severity=4, 与上下文直接矛盾)
