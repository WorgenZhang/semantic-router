models/mom-fact-check-classifier、models/mom-hallucination-detector、models/tasksource-ModernBERT-base-nli这三个模型都是怎么训练出来的, 训练数据上有什么区别, 模型结构上有什么区别, 模型大小都是多少

  1. mom-fact-check-classifier — 事实核查分类器

  训练方式：LoRA 微调（参数高效微调）

  - 基座模型：默认 llm-semantic-router/mmbert-32k-yarn（mmBERT-32K），也支持 answerdotai/ModernBERT-base
  - LoRA 配置：rank=16, alpha=32, dropout=0.1
  - 最大序列长度：mmbert-32k → 32768，modernbert-base → 8192

  模型结构：序列分类（Sequence Classification）
  - ModernBertForSequenceClassification
  - 2 个输出类别：FACT_CHECK_NEEDED / NO_FACT_CHECK_NEEDED
  - 输入：用户的问题文本 → 输出：是否需要事实核查

  训练数据：18 个数据集，50K+ 样本

  2. mom-hallucination-detector — 幻觉检测器

  训练方式：全参数微调（Full Fine-tuning）
  - 脚本：src/training/training_lora/hallucination_detection_classifier/finetune.py
  - 基座模型：llm-semantic-router/modernbert-base-32k
  - 注意：这里不是 LoRA，而是全参数微调

  模型结构：Token 级分类（Token Classification）
  - ModernBertForTokenClassification
  - 2 个输出类别：SUPPORTED(0) / HALLUCINATED(1)
  - 输入："{context} Question: {question} [SEP] {answer}" → 输出：answer 部分每个 token 的标签
  - 只对 [SEP] 之后（answer 区域）的 token 做预测

  训练数据：~21,290 样本，3 个数据集

  ┌──────────┬─────────┬────────────────────────────────────────────────────┐
  │  数据集  │ 样本量  │                        特征                        │
  ├──────────┼─────────┼────────────────────────────────────────────────────┤
  │ RAGTruth │ ~17,790 │ RAG 场景下的幻觉标注，包含 span 级别的幻觉位置标注 │
  ├──────────┼─────────┼────────────────────────────────────────────────────┤
  │ DART     │ ~2,000  │ 数据到文本生成的幻觉                               │
  ├──────────┼─────────┼────────────────────────────────────────────────────┤
  │ E2E      │ ~1,500  │ 端到端自然语言生成的幻觉                           │
  └──────────┴─────────┴────────────────────────────────────────────────────┘

  训练超参数：
  - 最大序列长度：8192
  - 批量大小：8
  - 学习率：1e-5
  - 训练轮数：6
  - 权重衰减：0.01
  - 预热比例：0.1

  性能指标： F1 = 76.56%（README 记录）

  3. tasksource/ModernBERT-base-nli — NLI 推理模型

  训练方式：第三方预训练模型（非自研）
  - 来源：HuggingFace tasksource/ModernBERT-base-nli
  - 由 tasksource 团队发布，直接下载使用
  - 本项目未对其进行额外微调

  模型结构：序列分类（Sequence Classification）
  - ModernBertForSequenceClassification（在 Rust 端用 TraditionalModernBertClassifier 加载）
  - 3 个输出类别：ENTAILMENT(0) / NEUTRAL(1) / CONTRADICTION(2)
  - 输入：premise [SEP] hypothesis → 输出：三分类概率
  - 在幻觉检测管线中：premise = "{context} {question}"，hypothesis = 检测到的幻觉 span 文本

  训练数据： 公开的 NLI 数据集（SNLI、MultiNLI、ANLI 等），由 tasksource 团队训练，具体配比未在本项目中记录。

  关于模型大小：
  - ModernBERT-base 约 149M 参数（22 层 Transformer，hidden_size=768）
  - fact-check 用 LoRA，额外参数仅 ~1.3M（rank=16 × 目标层数），总文件大小远小于全参数模型
  - hallucination-detector 和 NLI 模型都是全参数保存，磁盘大小约 ~600MB（包含 float32 权重）
  - mmBERT-32K 是 ModernBERT-base 的 YARN 长上下文变体，参数量基本相同，主要区别是 RoPE 插值支持 32K 上下文

  三者在管线中的协作关系：

  请求阶段                                响应阶段
     │                                      │
     ▼                                      ▼
  fact-check-classifier              hallucination-detector
    (需要核查？)                        (哪些token是幻觉？)
     │                                      │
     ├─ NO → 跳过幻觉检测                    ▼
     │                              ModernBERT-base-nli (可选)
     └─ YES → 设置标记 ──────────►    (ENTAILMENT→误报移除)
           等待响应到来                (CONTRADICTION→确认幻觉)
                                     (NEUTRAL→保留,降低严重度)
