## Bit 和 Channel 的含义

### Channel（通道）= 颜色分量

一个彩色像素由 3 个通道组成：

```
一个像素的颜色 = R（红） + G（绿） + B（蓝）

            ┌─── R 通道 (Red)
像素颜色 ───┼─── G 通道 (Green)
            └─── B 通道 (Blue)
```

就像调色：任何颜色都可以用红、绿、蓝三种光按不同比例混合出来。

---

### Bit（位）= 每个通道能表达多少级别

```
8-bit per channel:
  每个通道用 8 个二进制位来描述亮度
  2^8 = 256 级

  R: 0~255 (0=全黑, 255=最红)
  G: 0~255 (0=全黑, 255=最绿)
  B: 0~255 (0=全黑, 255=最蓝)
```

---

### 24-bit 怎么来的

```
24-bit = 3个通道 × 每通道8-bit

  R: 8-bit (256级)
  G: 8-bit (256级)
  B: 8-bit (256级)
  ─────────────────
  总计: 24-bit

可表达颜色总数: 256 × 256 × 256 = 16,777,216 种（约1677万色）
```

---

### 对比 18-bit

```
18-bit = 3个通道 × 每通道6-bit

  R: 6-bit (64级)
  G: 6-bit (64级)
  B: 6-bit (64级)
  ─────────────────
  总计: 18-bit

可表达颜色总数: 64 × 64 × 64 = 262,144 种（约26万色）
```

---

### 直观感受

```
8-bit/channel (256级):
  从黑到红有 256 个过渡阶梯 → 人眼看上去是平滑渐变

6-bit/channel (64级):
  从黑到红只有 64 个过渡阶梯 → 人眼能看到一条条色带（banding）
```

举例——一片日落天空的渐变：

```
8-bit: ████████████████████████  ← 平滑过渡，看不出断层
6-bit: ██▌██▌██▌██▌██▌██▌██▌██  ← 能看到一条条色阶分界线
```

所以"24-bit 8-bit/channel"就是说：每个像素用 24 个二进制位来记录颜色，红绿蓝各分到 8 位，每个颜色分量有 256 级精度。这是目前最通用的图像标准格式。
