## 为什么这三个条件下需要出 BSV 流

核心逻辑：**BSV (Blind Spot View) 是给"手动变道的驾驶员"看盲区的，只在人真正需要且系统能提供时才出流。**

---

### 条件 1：智驾未激活（纯手动驾驶）

```
智驾激活时:
  系统自己控制方向盘 → 系统自己能"看到"盲区 → 不需要给人看
  人不操控 → 给人看了也没意义，反而分散注意力

手动驾驶时:
  人自己决策变道 → 人自己看不到盲区 → 必须辅助显示给人看
```

**简单说：** 谁在开车，谁需要看盲区。智驾开车时机器自己有感知，不需要弹窗打扰人。

---

### 条件 2：打了转向灯

```
没打转向灯:
  驾驶员只是直行 → 不需要看盲区 → 不出流（避免屏幕一直有浮窗干扰）

打了转向灯:
  驾驶员明确表达"我要变道/转弯" → 这一刻盲区信息关乎安全 → 出流
```

**简单说：** 转向灯 = 驾驶员的变道意图信号。有意图才弹窗，没意图不打扰。

---

### 条件 3：对应鱼眼相机未降级

```
相机正常:
  能提供可靠画面 → 出流给驾驶员参考

相机降级（故障/遮挡/失效）:
  画面不可信（黑屏/花屏/严重偏色）→ 如果还出流，驾驶员看到错误画面
  → 可能误判"盲区没车"→ 变道撞车
  → 不如不显示，让驾驶员自己用物理后视镜确认
```

**简单说：** 宁可不显示，也不能显示一个错误的画面误导驾驶员。

---

### 三个条件组合的逻辑

```
BSV 出流 = 条件1 AND 条件2 AND 条件3

即：人在开车 + 人要变道 + 画面可靠 → 才出流

任何一个不满足：
  ├─ 智驾在开 → 机器自己处理，不打扰人
  ├─ 没打灯   → 人没变道意图，不干扰视线
  └─ 相机坏了 → 画面不可信，不误导人
```

---

### 一句话总结

BSV 本质是一个**安全辅助功能**——只在"人需要决策 + 人看不到 + 系统能给出可靠信息"这三者同时成立时才激活，既不过度打扰，也不提供错误信息。

## 缩写全称

| 缩写    | 英文全称          | 中文含义                        |
| ------- | ----------------- | ------------------------------- |
| CP      | City Pilot        | 城市领航辅助（城市道路智驾）    |
| NP      | Navigation Pilot  | 高速导航辅助（高速/快速路智驾） |
| Parking | Automated Parking | 自动泊车                        |

---

### 简单理解

```
NP (Navigation Pilot)
  → 高速/快速路上，系统帮你开车（自动跟车、变道、上下匝道）

CP (City Pilot)
  → 城市道路上，系统帮你开车（识别红绿灯、路口转弯、避让行人）

Parking
  → 停车时，系统帮你泊入/泊出车位
```

这三个都属于"系统控车"状态——方向盘、油门、刹车都由系统接管。只要其中任何一个激活，就意味着不是人在做变道决策，BSV 就不需要弹出来给人看。

## PMC 和 AVM 缩写全称

| 缩写 | 英文全称                     | 中文含义       |
| ---- | ---------------------------- | -------------- |
| PMC  | Peripheral Module Controller | 外围模块控制器 |
| AVM  | Around View Monitor          | 全景环视系统   |

---

### 在这个场景中的关系

```
PMC (外围模块控制器)
  → 负责管理各路摄像头的健康状态（是否正常工作、是否遮挡/故障）
  → 检测到某个鱼眼相机异常时，发出"降级"信号

AVM (全景环视系统)
  → 由 4 个鱼眼摄像头（SVC_F/SVC_R/SVC_SL/SVC_SR）组成
  → 拼接出车辆周围 360° 俯视图
  → BSV（盲区影像）就是从 AVM 的鱼眼相机中取单路画面
```

---

### 信息流

```
鱼眼相机硬件异常 → PMC 检测到 → 发出降级标志 → BSV 模块收到
→ 判定"该方向画面不可信" → 不出流
```
