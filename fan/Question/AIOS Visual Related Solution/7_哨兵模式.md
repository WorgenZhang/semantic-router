## 哨兵模式：摄像头配置 & 模型需求

---

### 功能拆解

```
哨兵模式包含两个子功能:

1. 自动值守（24h 监控）
   → 检测异常事件：有人靠近、碰撞、划车、偷窥
   → 自动录像取证
   → 推送告警到手机

2. 远程查看（手机 App 调起）
   → 车主主动看车周围环境
   → 找车/确认车辆安全
   → 实时视频流回传手机
```

---

### 摄像头选择

#### 自动值守：4 路 SVC 鱼眼

```
为什么选 SVC:
  ✅ 4 路拼起来 360° 全覆盖，无死角
  ✅ 可低帧率运行（1~5fps），极低功耗
  ✅ H200° 超广角，单路就覆盖半边车身
  ✅ 停车场景不需要高像素密度（人在 1~3m 内，够大）
  ✅ 装在车辆四角，位置天然适合周界监控

不选 FWC/SC 的原因:
  ❌ FWC: 8MP 功耗太高，只看前方，24h 开不起
  ❌ SC: 覆盖角度有限，有盲区，4 路全开功耗也不低
```

#### 远程查看：SVC 为主，按需唤醒 SC/FWC

```
场景 1: 车主想看车周围有没有人/车
  → 4 路 SVC 环视拼接画面推送到 App
  → 全景鸟瞰图 + 四个方向分画面

场景 2: 车主想看清某个方向细节（比如车门旁的划痕）
  → App 上点击某个方向 → 唤醒该侧 SC
  → SC 高清画面回传（3MP 无畸变）

场景 3: 停车场找车（车主在远处）
  → FWC 前视画面 + 闪灯/鸣笛配合定位
  → 但这个场景通常不需要摄像头，靠 GPS + 闪灯就行
```

---

### 推荐摄像头方案

| 模式 | 摄像头 | 帧率 | 功耗 | 用途 |
|------|--------|------|------|------|
| 常态值守 | 4路 SVC | 1~5fps | 极低 | 360° 监控检测 |
| 事件触发 | SVC + 对应侧 SC | 30fps | 中等 | 高清录像取证 |
| 远程查看 | SVC（全景）+ SC（细节） | 15~30fps | 中等 | App 实时画面 |

---

### 需不需要 CV 模型？

**需要。但是轻量级 CV 小模型，不需要 VLM。**

```
需要 CV 模型的场景:
  ├─ 人形检测: 有人靠近车辆 → 告警
  ├─ 运动检测: 画面中有物体移动 → 开始录像
  ├─ 碰撞/震动 + 视觉确认: 传感器触发后用摄像头确认
  └─ 人脸/身份: 拍下嫌疑人面部（用 SC 高清抓拍）

不需要 VLM 的原因:
  → 哨兵模式需要 7×24h 运行
  → VLM 算力需求大，功耗高，车辆熄火状态芯片扛不住
  → 任务简单：只需要"有没有人/有没有动"这类二分类
  → 不需要理解场景语义（不需要知道"这个人在干什么"）
```

---

### CV 模型具体需求

```
模型 1: 运动检测（最基础）
  方法: 帧差法 / 背景建模（甚至不需要 AI）
  功耗: 几乎为零
  作用: 有东西在动 → 触发下一级

模型 2: 人形/车辆检测
  模型: 轻量级目标检测（YOLO-Nano / MobileNet-SSD 级别）
  算力: <1 TOPS
  作用: 区分"是人"还是"树枝晃动/光影变化"，减少误报

模型 3: 事件分类（可选）
  输入: 运动区域 ROI
  分类: 路过/逗留/触碰车辆/砸窗
  作用: 不同级别告警（路过不报警，逗留才报警）
```

---

### 什么情况下可能用到 VLM？

```
如果未来想做"智能告警描述":

  普通 CV: 推送 → "检测到人形靠近车辆左侧" + 截图

  VLM 加持: 推送 → "一名穿外卖服的人骑电动车停在你车左侧，
                     正在查看车门，已逗留 45 秒" + 截图

  但这个可以:
    → 事件触发后，截图上传到云端 VLM 分析
    → 不需要车端实时跑 VLM
    → 云端处理延迟 2~3 秒可接受（不是驾驶安全场景）
```

---

### 功耗预算（关键约束）

```
车辆熄火后靠 12V 蓄电池供电:

典型蓄电池容量: 60Ah × 12V = 720Wh
保证能正常启动需预留: ~50%
可用于哨兵模式: ~360Wh

各方案功耗估算:
  4路 SVC (5fps) + 轻量 CV: ~3~5W → 可运行 72~120 小时 ✅
  4路 SVC + 4路 SC 全开:    ~15W  → 可运行 24 小时 ⚠️
  加上 VLM 推理:            ~30W+ → 可运行 12 小时 ❌

所以:
  常态: 只开 SVC + 轻量检测（保证续航 3~5 天）
  事件触发: 短暂唤醒 SC 录像（每次几十秒，不影响总续航）
```

### 整体架构

```
┌─────────────────────────────────────────────┐
│              哨兵模式架构                      │
│                                             │
│  [常态 - 低功耗]                             │
│   4路 SVC (1~5fps)                          │
│       ↓                                     │
│   帧差法/运动检测 (几乎零算力)                 │
│       ↓ 有运动                              │
│   轻量 CV 人形检测 (<1 TOPS)                  │
│       ↓ 确认是人                             │
│                                             │
│  [事件触发 - 中功耗]                          │
│   唤醒对应侧 SC (30fps 录像)                  │
│   持续录制 30~60 秒                          │
│   推送告警到手机 App                          │
│       ↓ (可选)                              │
│   截图上传云端 VLM 生成事件描述                 │
│                                             │
│  [远程查看 - 按需]                            │
│   车主打开 App → 唤醒 SVC/SC                  │
│   视频流编码 → 4G/5G 回传 → App 显示          │
│                                             │
└─────────────────────────────────────────────┘
```

---

### 一句话总结

哨兵模式用 **4 路 SVC 鱼眼低功耗常态监控 + 轻量 CV 小模型做人形检测**即可，不需要车端 VLM。事件触发后短暂唤醒 SC 高清录像取证，远程查看时按需回传视频流。功耗控制是核心约束，决定了只能用最轻量的方案。
