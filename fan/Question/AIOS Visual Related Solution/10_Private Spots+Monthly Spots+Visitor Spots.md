## 停车限制识别：摄像头 + 模型方案

---

### 识别目标分类

```
Parking Restriction (停车限制):

  Private Spots (私人车位)
    → 地面喷字 "私人车位"/"专用"、地锁、车位号
    
  Monthly Spots (月租车位)
    → 地面喷字 "月租"/"VIP"、车位牌、编号

  Fire Lanes (消防通道)
    → 地面黄色网格线 + "消防通道 禁止停车"
    → 路缘石红色/黄色涂装
    → 墙面标识牌

  Visitor Spots (访客车位)
    → 地面喷字 "访客"/"临时"
    → 指示牌

  Charging-Only Spots (充电专用车位)
    → 地面绿色标识 + 充电桩图标
    → 充电桩设备实体
    → "充电专用 禁止占用" 文字

  Time-Limited Parking (限时停车)
    → 路侧牌 "限时30分钟"/"P 8:00-18:00"
    → 地面蓝色/白色标线 + 时间文字
```

---

### 摄像头需求分析

#### 核心区别：停车场景 vs 行车场景

```
行车场景 (之前的路牌识别):
  → 目标在前方远处 (20~200m)
  → 高速经过，需要提前识别
  → FWC + FTC 为主

停车场景 (本次):
  → 目标在近距离 (1~10m)
  → 低速 (<10km/h) 或静止状态
  → 目标在地面、路侧、正前方都有
  → 需要多方向覆盖
```

---

### 各摄像头在停车场景中的角色

```
┌──────────────────────────────────────────────────────┐
│            停车场内各标识的物理位置                      │
│                                                      │
│  地面喷字 (私人/月租/访客/充电)                         │
│    → 在车位内部或车位前方地面                           │
│    → 距离 2~8m，在车辆正前方偏下                       │
│    → 需要: FWC (看远) + SVC_F (看近处地面)             │
│                                                      │
│  地锁/充电桩 (实体设备)                                │
│    → 在车位正中或旁边，高度 0.3~1.5m                   │
│    → 距离 1~5m                                        │
│    → 需要: FWC + SVC_F (近距离低矮物体)                │
│                                                      │
│  路侧/墙面标识牌 (限时/消防/指示)                       │
│    → 在车辆两侧或前方墙壁上                            │
│    → 高度 1~2.5m                                      │
│    → 需要: FWC + SC_FL/SC_FR (侧方)                   │
│                                                      │
│  路缘石/地面标线颜色 (消防通道黄线/红线)                 │
│    → 地面边缘，近距离                                  │
│    → 需要: SVC (环视看地面边缘)                        │
│                                                      │
└──────────────────────────────────────────────────────┘
```

---

### 摄像头方案

| 摄像头 | 角色 | 在停车限制识别中的用途 |
|--------|------|----------------------|
| FWC (8MP, H120°) | **主力** | 前方车位标识、文字、充电桩、指示牌 |
| SVC_F (前鱼眼, H200°) | **近地面主力** | 正前方 1~3m 地面喷字、地锁、路缘石颜色 |
| SC_FL / SC_FR | **侧方辅助** | 两侧墙面标识牌、限时牌、消防警告牌 |
| SVC_SL / SVC_SR | 补充 | 两侧近距离地面标线颜色、路缘石涂装 |
| RVC + SVC_R | 泊入确认 | 倒车入库时确认车位内标识 |

---

### 为什么停车场景 SVC 变得有用了

```
行车场景下 SVC 没用:
  → 目标远 (20~200m)，SVC 像素密度太低看不清
  → 需要识别文字，SVC 畸变导致文字变形

停车场景下 SVC 有用:
  → 目标极近 (1~3m)，即使像素密度低也占够像素
  → 地面喷字在 1~3m 距离下在 SVC 中足够大
  → SVC 安装位置低（车头底部），天然适合看地面
  → 超广角 200° 覆盖车位两侧地面标线

对比:
  地面 "私人车位" 四个字（宽约 1m）在 3m 距离:
    FWC: 视角 ≈ 19° → 19° × 32 px/° = 608px ← 超清晰
    SVC_F: 视角 ≈ 19° → 19° × 9.8 px/° = 186px ← 足够识别
```

### 各目标识别详细方案

#### 1. Private Spots / Monthly Spots / Visitor Spots（文字类车位）

```
共同特点: 依赖地面喷字识别

摄像头:
  远距离 (5~10m): FWC → 提前看到"前方车位有字"
  近距离 (1~3m): SVC_F → 看清地面具体文字内容
  倒车时: RVC + SVC_R → 确认正在进入的车位标识

模型: CV + OCR ✅ (不需要 VLM)
  Step 1: 车位线检测（CV 分割）→ 定位车位区域
  Step 2: 车位内 ROI 文字检测（OCR）→ "私人"/"月租"/"访客"
  Step 3: 分类判定 → 该车位是否可停

为什么不需要 VLM:
  → "私人车位"/"月租"/"访客" 是固定词汇
  → OCR 读出文字后直接关键词匹配即可
  → 不需要理解语义
```

#### 2. Fire Lanes（消防通道）

```
特征组合:
  → 地面: 黄色网格线 + "消防通道" 文字
  → 路缘石: 红色或黄色涂装
  → 墙面: "消防通道 禁止停车" 标识牌
  → 环境: 通常较宽、无车位线

摄像头:
  地面网格线: FWC + SVC_F
  路缘石颜色: SVC_SL / SVC_SR（侧向近地面）
  墙面标识: SC_FL / SC_FR

模型: CV 为主
  → 黄色网格线检测: 颜色+纹理特征（CV 分割）
  → 路缘石颜色分类: 红/黄/无涂装（CV 分类）
  → "消防通道" 文字: OCR
  → 多特征融合 → 判定为消防通道

  规则: 满足 2 个以上特征 → 高置信度判定消防区域
```

#### 3. Charging-Only Spots（充电专用车位）

```
特征组合:
  → 地面: 绿色标识 + 充电图标 + "充电专用" 文字
  → 实体: 充电桩设备（立柱式/壁挂式）
  → 车位线: 通常为绿色

摄像头:
  充电桩实体: FWC (前方 3~10m 检测到立柱)
  地面绿色标识: SVC_F (近处地面)
  文字: FWC + SVC_F

模型: CV 目标检测 + OCR
  → 充电桩检测: YOLO 级别物体检测（检测充电桩外形）
  → 绿色标线/图标: 颜色分割 + 图标分类
  → "充电专用" 文字: OCR

  比较简单: 充电桩是高辨识度的实体目标
  有桩 + 绿色地标 = 充电车位，几乎无歧义
```

#### 4. Time-Limited Parking（限时停车）

```
特征:
  → 路侧立牌: "限时停车 30分钟" / "P 8:00-18:00"
  → 地面: 蓝色或白色虚线标线
  → 有时配合电子计时器

摄像头:
  路侧立牌: FWC (前方远距离) + SC_FL/SC_FR (近距离侧方)
  地面标线: FWC + SVC_F

模型: OCR + 规则引擎 ✅
  Step 1: 检测路侧 P 牌 (CV 检测)
  Step 2: 读取牌面文字 (OCR) → "限时30分钟" / "8:00-18:00"
  Step 3: 解析时间规则 (规则引擎)
    → 提取时间段: 8:00-18:00
    → 对比当前时间: 现在是 14:30
    → 判定: 当前在限制时段内，限停 30 分钟

  这里是否需要 VLM？
  → 标准格式牌: 不需要，OCR + 正则匹配够了
  → 复杂描述牌 (如"周末及法定假日除外"): 
    → 可能需要 VLM 理解自然语言规则
    → 或预置规则库覆盖常见表述
```

### 模型架构总结

```
┌──────────────────────────────────────────────────────────┐
│              停车限制识别 - 模型分层                        │
│                                                          │
│  [Layer 1: CV 检测/分割] — 车端实时                        │
│                                                          │
│   车位线检测与分割         ─── ~2 TOPS ─── <50ms          │
│   地面颜色区域分割         ─── ~1 TOPS ─── <50ms          │
│   (黄色网格/绿色充电/蓝色限时)                             │
│   物体检测                ─── ~2 TOPS ─── <50ms          │
│   (充电桩/地锁/路缘石/立牌)                               │
│   路缘石颜色分类           ─── ~0.5 TOPS── <30ms          │
│                                                          │
│  [Layer 2: OCR 文字识别] — 车端                            │
│                                                          │
│   地面喷字                ─── ~1 TOPS ─── <100ms          │
│   ("私人"/"月租"/"访客"/"消防"/"充电专用")                  │
│   牌面文字                ─── ~1 TOPS ─── <100ms          │
│   ("限时30分钟"/"P 8:00-18:00")                           │
│                                                          │
│  [Layer 3: 规则引擎] — 车端，零算力                        │
│                                                          │
│   时间规则解析: "8:00-18:00" + 当前时间 → 是否限制中       │
│   多特征融合: 黄色网格 + 消防文字 + 红色路缘 → 消防通道    │
│   停车决策: 可停 / 不可停 / 有条件可停                     │
│                                                          │
│  [Layer 4: VLM] — 云端按需 (极少触发)                      │
│                                                          │
│   复杂自然语言规则牌理解                                   │
│   ("周末及法定节假日全天禁止停车，工作日18:00后可停")        │
│   非标准手写/打印告示理解                                  │
│   ("业主车辆请停B2层，访客请停B1" )                         │
│                                                          │
│   总车端算力: ~7-8 TOPS                                   │
└──────────────────────────────────────────────────────────┘
```

### VLM 在停车场景中的独特价值

```
大部分停车标识: CV + OCR 够了（标准化文字）

但真正需要 VLM 的场景:

1. 复杂规则理解:
   牌面写着: "本车位仅限3号楼业主使用，违者锁车"
   → OCR 能读出文字
   → 但需要 VLM 理解"我是不是3号楼业主"这层语义
   → 结合用户信息判断"能不能停"

2. 非标准告示:
   A4 纸打印贴在墙上: "此处装修施工，临时禁止停车 —物业"
   → 手写/打印体 OCR 可能识别率低
   → VLM 对非标准文本鲁棒性更好

3. 环境综合判断:
   没有任何文字标识，但:
   → 车位上摆着锥桶/椅子占位
   → 车位旁有人站着"看车"
   → 这种需要理解"这个车位虽然空但不能停"
   → 纯 CV 无法判断，需要 VLM 场景理解

4. 多语言场景:
   海外停车场: "Reserved for Dr. Smith, Mon-Fri"
   → 需要理解英文 + 时间规则 + 人名含义
```

### 各目标最终方案

| 停车限制类型 | 主摄像头 | 辅助摄像头 | 模型 | VLM? |
|-------------|---------|-----------|------|------|
| 私人车位 | FWC + SVC_F | RVC | CV + OCR | 一般不需要 |
| 月租车位 | FWC + SVC_F | RVC | CV + OCR | 不需要 |
| 消防通道 | FWC + SVC_F | SC + SVC侧 | CV 分割 + OCR | 不需要 |
| 访客车位 | FWC + SVC_F | RVC | CV + OCR | 不需要 |
| 充电专用 | FWC | SVC_F | CV 检测 + OCR | 不需要 |
| 限时停车 | FWC + SC侧 | SVC_F | OCR + 规则 | 复杂规则时需要 |
| 非标准告示 | FWC + SC | - | OCR + VLM | 需要 |

### 与行车场景的对比

```
行车 (路牌/标线识别):
  摄像头: FWC + FTC 为主
  SVC: 完全不参与
  距离: 20~200m
  速度: 高速
  重点: 远距离提前识别

停车 (车位限制识别):
  摄像头: FWC + SVC_F 为主，SC 辅助
  SVC: 参与（近距离地面识别）
  距离: 1~10m
  速度: 极低速/静止
  重点: 近距离精确读取

关键差异: SVC 在停车场景中有价值
  → 因为目标近 + 目标在地面 + SVC 安装位置低
```

---

### 一句话总结

停车限制识别主要靠 **FWC + SVC_F（看前方和近地面）+ SC（看侧方牌面）**配合 **CV 检测 + OCR 文字识别 + 规则引擎**实现。与行车场景不同，SVC 鱼眼在低速近距离停车场景中变得有用。VLM 仅在遇到复杂自然语言规则牌或非标准告示时按需触发。
