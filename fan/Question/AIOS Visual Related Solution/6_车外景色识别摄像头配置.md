## 行车场景识别 & 拍照：FWC 够不够？

### 结论：FWC 为主力，但如果要"拍照留念"和"沉浸式氛围"，最好加 SC

---

### 三个功能拆解

| 功能 | 核心需求 | 关键约束 |
|------|---------|---------|
| 识别地标/动物/植物 | 看清是什么 | 分辨率、前方视角 |
| 沉浸式氛围生成 | 理解整体环境（海边/山林/城市） | 覆盖范围、色彩感知 |
| 抓拍美景照片 | 构图好看、像素高 | 画质、视角多样性 |

---

### 只用 FWC 的情况

```
FWC 能做到的:
  ✅ 识别正前方地标（建筑物、山峰、路牌）
  ✅ 识别前方路上的动物（鹿、牛等横穿）
  ✅ 判断大致环境（前方是海/山/城市天际线）
  ✅ 抓拍前方风景

FWC 做不到的:
  ❌ 侧面的风景（窗外的湖泊、花海、日落）
  ❌ 车已经开过了的地标（在后方了）
  ❌ 左右两侧不同的景色氛围
  ❌ 多角度构图的"好照片"
```

---

### 实际场景举例

```
场景 1: 沿海公路行驶，右侧是大海

  FWC: 看到的是前方道路 + 一点点海岸线边缘
  SC_FR (右前侧 H120°): 完整的海面 + 日落 + 海岸线 ← 真正的美景在这

  只用 FWC → 氛围判断可能是"公路"而不是"海边"
  加上 SC_FR → 识别到大面积蓝色海面 → 触发"海洋氛围"

场景 2: 穿越林荫大道，两侧是樱花

  FWC: 看到前方道路，两侧树木在画面边缘
  SC_FL + SC_FR: 左右两侧铺满的樱花树 ← 沉浸感来源

  只用 FWC → 可能识别为"普通树木道路"
  加 SC → 识别到粉色樱花覆盖 → 触发"春日花海氛围"

场景 3: 路边突然出现一只鹿

  鹿在右前方 30° 位置 → 在 FWC H120° 范围内 ✅
  但如果鹿在右侧 80° 位置 → FWC 看不到 ❌ → SC_FR 能看到

场景 4: 抓拍美景照片

  只有 FWC → 所有照片都是"前方道路视角"，构图单一
  加 SC → 可以拍侧面风景（湖面倒影、山体全貌、日落）
  → 照片更有"窗外看出去"的感觉，更像人拍的
```

### 各摄像头的角色分工

```
┌─────────────────────────────────────────┐
│              识别 & 拍照功能              │
├─────────────┬─────────────┬─────────────┤
│    FWC      │   SC_FL/FR  │    SVC      │
│   前方主力   │   侧方补充   │   不适合     │
├─────────────┼─────────────┼─────────────┤
│ • 地标识别   │ • 侧方美景   │ ❌ 像素密度低 │
│   (正前方)   │ • 日出日落   │ ❌ 鱼眼畸变大│
│ • 环境大类   │ • 湖海山林   │ ❌ 照片不可用│
│   判断      │ • 拍照构图   │             │
│ • 前方抓拍   │ • 氛围补充   │             │
│ • 动植物     │   信息       │             │
│   (前方出现) │             │             │
└─────────────┴─────────────┴─────────────┘
```

---

### 为什么 SVC 不适合这个场景

```
SVC 鱼眼:
  → H200° 看得广但每度像素太少 (9.8 px/°)
  → 鱼眼畸变严重，拍出来的"照片"变形扭曲
  → 装在车头/车尾偏低位置，视角不是人眼视角
  → 拍出的照片不能给用户看（不美观）

SC 标准镜头:
  → H120° 足够覆盖侧面主要景色
  → 无畸变，拍出来像正常照片
  → 装在后视镜高度，接近人从车窗看出去的视角
  → 3MP 照片质量可接受
```

---

### 推荐方案

| 功能层 | 最小配置 (只有FWC) | 推荐配置 (FWC + SC) |
|--------|-------------------|-------------------|
| 地标识别 | ✅ 前方地标可识别 | ✅ 前方+侧方都能识别 |
| 氛围生成 | △ 只看前方，判断粗略 | ✅ 360°环境感知，氛围更准 |
| 拍照留念 | △ 只有前方构图 | ✅ 多角度、侧面风景照 |
| 动植物识别 | △ 只覆盖前方 | ✅ 侧方出现的也能捕捉 |

---

### 一句话总结

**FWC 能做"识别"，但做不好"拍照"和"氛围"。** 美景往往在两侧（海边、山谷、日落），不在正前方道路上。如果要让功能体验真正好用，至少需要 FWC + SC_FL + SC_FR 三路配合：FWC 负责前方识别，SC 负责侧方感知和抓拍出构图好看的照片。
