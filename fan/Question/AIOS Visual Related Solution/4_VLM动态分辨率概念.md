## 动态分辨率和多 Tile 的关系

**动态分辨率是"策略"，多 Tile 是"手段"。** 动态分辨率通过智能选择 tile 数量和排布来实现。

---

### 对比：固定分辨率 vs 动态分辨率

```
固定分辨率（老方案）:
  不管输入什么图，统一 resize 到 448×448，1 个 tile
  → 所有图都一视同仁，简单但浪费

动态分辨率（新方案）:
  根据输入图的尺寸和宽高比，自动选最优的 tile 切分方案
  → 大图多切几块，小图少切，窄长图和宽图用不同排布
```

---

### 动态分辨率的决策过程

```
输入图像 3840×2160 (16:9)

Step 1: 模型内置一组候选 tile 排布方案
  1×1, 1×2, 2×1, 2×2, 2×3, 3×2, 2×4, 4×2, 3×3, 3×4, 4×3 ...

Step 2: 计算每种方案的"浪费率"
  目标: 找到最匹配原图宽高比、且不超过 tile 上限的方案

  4×2 → 覆盖比例 1792×896 → 宽高比 2:1 ≈ 接近 16:9 ✓
  3×2 → 覆盖比例 1344×896 → 宽高比 3:2 → 不太匹配
  2×2 → 覆盖比例 896×896  → 正方形 → 浪费多

Step 3: 选择最优方案
  → 选 4×2 = 8 tiles
```

### 总结关系

```
动态分辨率
    │
    ├── 是什么？ 根据输入图自动调整处理策略
    │
    ├── 怎么实现？ 通过选择不同数量和排布的 tile
    │
    └── 和多 tile 的关系:
          多 tile = 执行层面（把图切成块）
          动态分辨率 = 决策层面（决定切几块、怎么切）
```

简单类比：多 tile 是"刀"，动态分辨率是"切法"——根据食材（图像）的形状大小，选择横切、竖切、切几刀。
