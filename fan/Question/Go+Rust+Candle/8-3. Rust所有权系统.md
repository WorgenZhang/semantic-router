## Rust 所有权系统（Ownership）详解

所有权系统是 Rust 用来**在编译期自动管理内存**的机制，不需要垃圾回收器（GC），也不需要手动 `malloc/free`。它有**三条核心规则**：

### 三条规则

| 规则                                          | 说明                      |
| --------------------------------------------- | ------------------------- |
| **1. 每个值有且仅有一个所有者**         | 变量绑定就是所有权        |
| **2. 同一时刻只能有一个所有者**         | 赋值 = 所有权转移（Move） |
| **3. 所有者离开作用域时，值被自动释放** | 无需手动 free             |

---

### 例子 1：所有权转移（Move）

```rust
fn main() {
    let s1 = String::from("hello");  // s1 拥有这块堆内存
    let s2 = s1;                      // 所有权从 s1 转移到 s2
  
    println!("{}", s1);  // ❌ 编译错误！s1 已经不再拥有数据
    println!("{}", s2);  // ✅ 正常，s2 是新的所有者
}
```

**对比其他语言：**

```
C/C++:   s1 和 s2 都指向同一块内存 → 可能出现 double free
Java/Go: s1 和 s2 都指向同一个对象 → GC 负责回收
Rust:    s1 的所有权转移给 s2 → 编译器禁止再使用 s1
```

---

### 例子 2：函数调用也会转移所有权

```rust
fn take_ownership(s: String) {
    println!("got: {}", s);
}  // ← s 在这里被自动释放（drop）

fn main() {
    let name = String::from("semantic-router");
    take_ownership(name);      // name 的所有权转移给函数参数 s
  
    println!("{}", name);      // ❌ 编译错误！name 已经没有所有权了
}
```

---

### 例子 3：借用（Borrowing）— 不转移所有权

如果不想转移所有权，可以**借用**（用 `&` 引用）：

```rust
fn print_length(s: &String) {   // 借用，不拿走所有权
    println!("length: {}", s.len());
}  // ← s 是借用，这里不释放原始数据

fn main() {
    let name = String::from("semantic-router");
    print_length(&name);        // 传递引用，name 保留所有权
  
    println!("{}", name);       // ✅ 正常！name 仍然有效
}
```

---

### 例子 4：可变借用 — 同一时刻只能有一个

```rust
fn main() {
    let mut data = String::from("hello");
  
    let r1 = &mut data;         // 可变借用
    let r2 = &mut data;         // ❌ 编译错误！同时存在两个可变借用
  
    // 这条规则 防止了 数据竞争（data race）
}
```

**关键对比：**

|              | Go / C                                | Rust                                |
| ------------ | ------------------------------------- | ----------------------------------- |
| 分配内存     | `C.CString()` / `malloc()`        | `String::from()`                  |
| 释放内存     | **必须手动** `defer C.free()` | **自动**，离开作用域即释放    |
| 忘了释放     | 内存泄漏 ⚠️                         | **不可能**，编译器保证 ✅     |
| 用了已释放的 | Use-after-free 崩溃 💥                | **编译错误**，不让你这么做 ✅ |

---

### 一句话总结

> **所有权系统 = 编译器在编译时跟踪每块内存的"主人"是谁，确保每块内存恰好被释放一次，不多不少。** 这就是 Rust 不需要 GC 也能安全管理内存的核心秘密。
>
