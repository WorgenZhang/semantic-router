# 幻觉检测

在响应体阶段对 LLM 输出进行幻觉检测，判断响应内容是否与提供的上下文（RAG/Tool 结果）一致。

## 检测条件

必须同时满足：
- 分类器已启用幻觉检测
- Decision 的 hallucination 插件已启用
- ctx.FactCheckNeeded == true
- 有 tool/RAG 上下文可供对比

## 检测方式

- **基础检测**：`r.Classifier.DetectHallucination()`
- **NLI 增强检测**：`DetectHallucinationWithNLI()` — 自然语言推理

## 处理策略

| action | 行为 |
|--------|------|
| header | 添加 x-hallucination-detected 等响应头 |
| body | 在响应内容前添加警告文本 |
| block | 直接返回错误响应 |
| none | 不做处理 |

## 执行时机

位于 handleResponseBody 的第 13-14 步，在语义缓存更新（第 9 步）之后执行。设计意图：即使幻觉检测失败，原始响应已被缓存，不丢失数据。

## 检测举例

```
用户: "根据文档，公司2024年的收入是多少？"
文档上下文: "2024年公司总收入为5.2亿美元"
LLM 回答: "根据文档，公司2024年的收入为8.7亿美元。" ← 幻觉

NLI 模型判定: CONTRADICTION, confidence=0.95
HallucinationSpans: ["8.7亿美元"]
```
