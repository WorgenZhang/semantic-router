# 分布式追踪

基于 OpenTelemetry 的分布式追踪系统，通过 Trace ID 将分散在不同服务中的 Span 串联起来，实现请求全链路可观测。

## 核心概念

- **Trace**：一个完整请求的全程追踪（类比快递单号）
- **Span**：追踪中的一个阶段/步骤（类比快递在两站之间的一段旅程）
- **Trace ID**：贯穿所有服务的唯一标识
- **traceparent**：W3C 标准 header，格式 `00-{traceId}-{spanId}-{flags}`

## 在 ExtProc 中的 Span 结构

```
request_received (整体)
├── semantic_classify (信号评估)
├── upstream_request (发到 vLLM 的耗时)
└── response_process (幻觉检测/缓存)
```

## 关键代码

```go
ctx.TraceContext = tracing.ExtractTraceContext(baseCtx, headerMap)
spanCtx, span := tracing.StartSpan(ctx.TraceContext, tracing.SpanRequestReceived)
tracing.SetSpanAttributes(span, attribute.String("http.method", method))
```

Jaeger / Grafana Tempo — 可以搜索 request_id、查看耗时分布
