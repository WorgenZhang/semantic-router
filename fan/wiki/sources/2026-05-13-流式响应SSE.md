# 流式响应 SSE 概念解释

## 核心观点

- 非流式响应：等待完整生成后一次性返回 JSON
- 流式响应：设置 `"stream": true`，服务器逐 token 推送 SSE 事件（`data: {...}\n\n`）
- 流式中途断开时标记 StreamingAborted，防止缓存不完整响应
- 相关字段生命周期：ExpectStreamingResponse → IsStreamingResponse → StreamingChunks → StreamingComplete/StreamingAborted

## SSE 数据格式

```
data: {"choices":[{"delta":{"content":"特"}}]}
data: {"choices":[{"delta":{"content":"斯"}}]}
...
data: [DONE]
```

## 状态矩阵

| 情况 | IsStreamingResponse | StreamingComplete | 结果 |
|------|----|----|------|
| 普通响应正常返回 | false | - | 正常处理 |
| 流式响应完整接收 | true | true | 可以缓存 |
| 流式响应中途断开 | true | false | StreamingAborted，不缓存 |
