# ExtProc 四阶段初窥

## 核心观点

- ExtProc 采用经典的 `for { stream.Recv() → switch → handle → sendResponse }` gRPC 流式处理模式
- 四个处理阶段：请求头 → 请求体 → 响应头 → 响应体，分别对应四个 handler 函数
- 错误处理分为四层优先级：流式中断检测 > EOF 正常结束 > gRPC 状态码 > Go context 取消

## 关键概念

- [[ExtProc]]：Envoy gRPC External Processor 的核心事件循环
- [[OpenAIRouter]]：Process() 方法实现调度循环
- [[流式响应 SSE]]：StreamingAborted 标志防止缓存不完整响应

## 架构概览

```
Envoy gRPC Stream → stream.Recv() → switch req.Request.(type)
  ├─ RequestHeaders  → handleRequestHeaders()
  ├─ RequestBody     → handleRequestBody()
  ├─ ResponseHeaders → handleResponseHeaders()
  └─ ResponseBody    → handleResponseBody()
```
