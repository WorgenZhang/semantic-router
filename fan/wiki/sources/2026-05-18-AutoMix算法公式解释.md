# AutoMix 算法公式解释

> 详细拆解 AutoMix POMDP 价值函数每个变量的来源、含义和计算方式

## 基本信息

- 类型：技术文档 / 公式详解
- 主题：AutoMix 价值函数变量溯源

## 核心观点

1. **公式 `V(model) = Quality - λ×Cost + γ×(1-P_verify)×E[V(larger)]`** 中每个值都有明确来源
2. **Quality** 来自 benchmark 评估平均分；**Cost** 是归一化推理价格
3. **P_verify 是 AutoMix 最关键的创新**：通过 Few-shot Self-Verification 让模型自己判断答案是否正确
4. **E[V(larger)] 递归计算**：从最大模型开始反向推导，体现"失败了还能升级"的期望收益
5. **小模型期望价值最高**的反直觉结论：因为便宜 + 升级保底，所以系统优先用小模型

## 变量来源对照表

| 变量 | 含义 | 来源方式 |
|------|------|----------|
| Quality | 模型平均答对率 | 历史评估 / benchmark |
| λ | 成本敏感度 | 手动设定超参（默认 0.5） |
| Cost | 归一化推理价格 | raw_cost / max_cost |
| γ | 升级价值折扣 | 手动设定超参（默认 0.95） |
| P_verify | 自信能搞定的概率 | 模型自我验证统计 |
| E[V(larger)] | 升级后能获得的价值 | 从大到小递归计算 |

## 数值示例

```
V(405b) = 0.97 - 0.5×(10/10) + 0 = 0.47
V(70b)  = 0.90 - 0.15 + 0.95×0.15×0.47 = 0.817
V(8b)   = 0.75 - 0.025 + 0.95×0.35×0.817 = 0.997  ← 最高！
```
