# 分布式追踪和 Span 概念

## 核心观点

- Trace = 一个完整请求的全程追踪（类比快递单号）
- Span = 追踪中的一个阶段/步骤（类比快递在两站之间的一段旅程）
- Trace ID 贯穿所有服务，通过 traceparent header 传递
- 在 ExtProc 中创建 4 个 Span：request_received → semantic_classify → upstream_request → response_process

## 在 Jaeger 中的可视化效果

```
Trace ID: aaa-bbb-ccc-ddd     总耗时: 1.250s
├── Span 1: request_received    0ms ~ 1250ms (整体)
│   ├── Span 2: semantic_classify  5ms ~ 50ms (45ms)
│   ├── Span 3: upstream_request   51ms ~ 1200ms (1149ms) ← 最耗时
│   └── Span 4: response_process   1200ms ~ 1250ms (50ms)
```

## 关键代码

```go
ctx.TraceContext = tracing.ExtractTraceContext(baseCtx, headerMap)  // 恢复/新建 Trace
spanCtx, span := tracing.StartSpan(ctx.TraceContext, tracing.SpanRequestReceived)  // 创建 Span
tracing.SetSpanAttributes(span, attribute.String("http.method", method))  // 打标签
```
