# 模型路由机制

## 概述

vLLM 语义路由的核心能力：根据用户请求内容，智能选择最合适的 LLM 模型和端点。

## 路由流程

1. [[Signal Evaluation]] — 11 种信号分析用户内容
2. [[Decision Engine]] — AND/OR 规则匹配 Decision
3. 模型选择 — 从 Decision 的 model_pool 中选择
4. 端点路由 — selectEndpointForModel() 选择具体实例

## 路由路径分支

| 条件 | 路径 | 说明 |
|------|------|------|
| model != "auto" | 指定模型路由 | 直接路由到对应端点 |
| Anthropic 模型 | Anthropic 路由 | OpenAI → Anthropic 格式转换 |
| Looper 配置 | Looper 执行 | 多步推理循环 |
| model == "auto" | Auto 模型路由 | 完整信号评估 + Decision 选择 |

## 模型选择算法

通过 [[ModelSelector-Registry]] 执行 9 种算法，详见 [[模型选择算法]] 主题页。

- 在线方法：[[Static选择算法]]、[[Elo评分系统]]、[[RouterDC]]、[[AutoMix]]、[[Hybrid混合加权]]
- ML 方法（[[Linfa]]/[[Candle]] 推理）：[[KNN选择算法]]、[[KMeans选择算法]]、[[SVM选择算法]]、[[MLP选择算法]]

## 最终输出

HeaderMutation（路由 headers）+ BodyMutation（改写 model 字段 + 注入 system prompt）
